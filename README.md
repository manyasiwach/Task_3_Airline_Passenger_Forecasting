# ✈️ Airline Passenger Forecasting

## 📌 Project Overview
This project performs Time Series Forecasting on the Airline Passengers dataset using the SARIMA model.

## 📂 Dataset
- airline-passengers.csv
- Monthly airline passenger data

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Scikit-learn

## 📊 Project Steps
- Data Loading
- Data Exploration
- Time Series Visualization
- Quarterly Resampling
- Seasonal Decomposition
- Moving Average
- Train-Test Split
- SARIMA Model
- Forecasting
- RMSE Evaluation

## 📈 Result
The SARIMA model was used to forecast future airline passenger values and evaluate forecasting performance using RMSE.
